# RayFighers Multiplayer Server

## Getting Started

Make sure you have a working version of go.
1. install dependencies `go get`
2. clone the [maps repo](https://github.zhaw.ch/raycasters/maps) inside the server repo `git clone https://github.zhaw.ch/raycasters/maps`
3. run the server `go run main.go`

## Documentation

For in-depth information on the different components of the server and how they interact with each other check the [Server Wiki](https://github.zhaw.ch/raycasters/docs/wiki/Server).
